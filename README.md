## 작성 원칙
- 템플릿을 복사하지 않고, 코드가 실제로 저장하고 삭제하는 항목을 기준으로 작성했습니다.
- 법령 해석이 필요한 부분은 개인정보보호위원회·공정거래위원회 질의 회신으로 확인한 범위만 반영했습니다. 회신은 법적 판단이 아닌 일반 해석이며, 약관의 적법성은 확인받지 못했습니다.
- 변경 내역은 커밋 이력으로 확인할 수 있습니다.
